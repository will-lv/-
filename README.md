# 使用说明
自制的网易云格式转换插件。将ncm格式转换为MP3或者flac格式。只需要直接下载即可用，无需配置环境。


使用说明：

1. 您的电脑上现在应该能看到一个名为 `拖拽转换.cmd` 的文件（如果不显示后缀名，可能只显示 `拖拽转换`）。
2. 找到您想要转换的 `.ncm` 音乐文件。
3. 直接将 `.ncm` 文件用鼠标左键按住，拖拽到 `拖拽转换.cmd` 的图标上，然后松开鼠标。
4. 一个黑色的窗口会弹出，显示转换进度。
5. 转换完成后，新的 `.mp3` 或 `.flac` 文件会出现在原文件同一个文件夹里。

注意：
- 本工具不需要安装 Python，也不需要联网。
- 是利用 Windows 自带的 PowerShell 和 .NET 功能运行的。
